## 🖼️ Как добавить фото?

### 1. **Распакуй архив**
```bash
unzip Project382-organized.zip
cd Project382
```

### 2. **Положи фото в нужные папки**

Каждая папка ждёт конкретные фото. Примеры имён файлов ниже.

### 3. **Закоммитай на GitHub**
```bash
git add .
git commit -m "Add images to gallery, rooms, facilities, etc"
git push origin main
```

## 🔧 Инструкция для следующего ИИ

**Привет, будущий ИИ!** Если ты видишь пустые папки в `images/`, значит:

1. **Структура готова** — HTML и CSS уже знают где искать фото
2. **Пути правильные** — в `index.html` всё ссылается на `./images/[папка]/[имя]`
3. **Твоя задача:**
   - Если юзер скинул фото архивом → распакуй их в правильные папки
   - Если фото отдельно → переименуй по примерам выше и положи в папки
   - Если нужно добавить новые фото → просто положи в нужную папку, HTML найдёт

**Пример:**
```
Юзер говорит: "Вот фото номеров"
↓
Ты их смотришь, видишь что это стандартные номера
↓
Переименовываешь в standard-1.jpg, standard-2.jpg и т.д.
↓
Кидаешь в images/rooms/
↓
Готово! Сайт сам подхватит
```

## 🚀 Как залить на GitHub Pages

1. **Создай репо** `Project382` на GitHub (если нет)
2. **Распакуй архив** локально
3. **Добавь фото** в папки `images/`
4. **Закоммитай:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit with design and empty image folders"
   git branch -M main
   git remote add origin https://github.com/Danya29745/Project382.git
   git push -u origin main
   ```
5. **Включи Pages:**
   - Settings → Pages → Source: main → Save
6. **Готово!** Через 1-2 минуты доступно по адресу:
   ```
   https://danya29745.github.io/Project382/
   ```
