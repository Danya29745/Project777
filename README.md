- **Строка 37**: Обновлён путь к фону
- **Было:** `url('./images/pagebackground.webp')`

## 🖼 Если фон не отображается

1. Проверьте, что файл есть в репозитории: `images/backgrounds/pagebackground.webp`.
2. Откройте напрямую `https://danya29745.github.io/Project777/images/backgrounds/pagebackground.webp`:
   - картинка открылась → проблема в кэше, нажмите Ctrl+F5;
   - ошибка 404 → файла нет в репозитории или он лежит не в той папке (проверьте регистр букв).
3. Откройте DevTools (F12) → **Network** → обновите страницу → найдите `pagebackground.webp`. Статус должен быть **200**. Если **404**, смотрите, по какому адресу браузер её ищет.
4. Проверьте, что в `css/styles.css` (строка 37) путь `../images/backgrounds/pagebackground.webp`.
5. Проверьте, что в `images/backgrounds/` лежит именно `.webp`, а не только заглушка.

## 🆘 Если что-то не работает

### Проблема: Иконки не видны

**Причина:** В проекте не подключена библиотека Tabler Icons

**Решение:** Убедитесь, что в `<head>` вашего `index.html` есть:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@tabler/icons@latest/tabler-icons.min.css">
```

Если её нет — добавьте эту строку в `<head>` перед закрывающим `</head>`

### Проблема: Текст выглядит странно

**Причина:** Может быть кеш браузера

**Решение:** Очистите кеш (Ctrl+Shift+Delete или Cmd+Shift+Delete) и обновите страницу (Ctrl+F5)

### Проблема: На мобильном выглядит неправильно

**Решение:** Проверьте, что у вас есть `<meta name="viewport" content="width=device-width, initial-scale=1">` в `<head>`
