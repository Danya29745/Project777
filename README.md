## 🆘 Если что-то не работает

### Проблема: Иконки не видны

**Причина:** В проекте не подключена библиотека Tabler Icons

**Решение:** Убедитесь, что в `<head>` вашего `index.html` есть:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@tabler/icons@latest/tabler-icons.min.css">
```

Если её нет — добавьте эту строку в `<head>` перед закрывающим `</head>`

### Проблема: Текст выглядит странно

**Причина:** Может быть кеш браузера

**Решение:** Очистите кеш (Ctrl+Shift+Delete или Cmd+Shift+Delete) и обновите страницу (Ctrl+F5)

### Проблема: На мобильном выглядит неправильно

**Решение:** Проверьте, что у вас есть `<meta name="viewport" content="width=device-width, initial-scale=1">` в `<head>`
